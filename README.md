# Image Compressor using K-Means

This Python app compresses images by using the K-means clustering algorithm to reduce the number of colors in the image. It can be used with any image and adjusts the image by grouping similar colors together.

## Features

- Choose an image to compress
- Set the number of color clusters (default is 16)
- Visualize and save the compressed image

###  2. Install dependencies:

###  3.Run the app:

###  4. Output:
